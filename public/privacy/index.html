隐私政策 / Privacy policy

维护者 / Maintainer: {{OWNER_NAME}} · {{OWNER_EMAIL}}

本服务仅供维护者本人使用，不接受公众注册。This service is for its owner only; public registration is unavailable.

读取范围 / Access

经本人授权，读取 Google Health 的活动与健身、健康指标与测量、睡眠三项只读数据，用于回答本人的查询和描述趋势。Google 登录另使用 openid email 验证本人身份。不会写入健康来源记录。

With consent, three Google Health read-only scopes cover activity/fitness, health measurements and sleep for the owner's questions and descriptive trends. Separate openid/email login verifies the owner. Source health records are never modified.

处理与存储 / Processing and storage

Cloudflare Workers 托管桥接服务；客户端密钥保存在 Worker Secrets，Google 访问与刷新令牌保存在 KV；MCP 授权记录由 Cloudflare OAuth 库管理。读取结果在 KV 缓存最多五分钟，并按本人请求提供给已连接的 ChatGPT/OpenAI。拥有 Cloudflare 账户管理权限的人可能访问凭据和缓存，应保护这些权限。

Cloudflare Workers hosts the bridge. Worker Secrets holds client secrets; KV holds Google access/refresh tokens and up to five minutes of read cache. The Cloudflare OAuth library manages MCP grants. Requested results are sent to the owner's connected ChatGPT/OpenAI. Cloudflare account administrators may access stored credentials and cache.

桥接服务不自行训练模型或出售数据。ChatGPT/OpenAI 的后续处理受本人账户、工作区的数据控制与相关条款约束。本服务不声称数据从不经过第三方。

The bridge does not itself train models or sell data. Downstream ChatGPT/OpenAI processing follows the owner's account/workspace data controls and applicable terms. Data does pass through these service providers.

可选归档 / Optional archive

如另行安装 Apps Script 归档，其 Drive drive.file 权限仅用于本应用创建或明确授权的文件；脚本另需外部请求和定时触发器权限。归档独立授权，输出保留至本人删除，桥接安装不会访问已有脚本或云盘。

If separately installed, the Apps Script archive uses Drive drive.file for app-created or explicitly authorized files, plus external-request and trigger permissions. It has independent consent. Archive output persists until deleted; bridge installation does not access existing scripts or Drive.

撤销与删除 / Revocation and deletion

可在 Google 账户连接设置撤销 Google 授权，在 ChatGPT 断开插件，并删除 Cloudflare 的 Health 令牌、缓存和 MCP 授权。撤销不会自动删除已生成的独立归档；如有归档，还应按需删除 Drive 输出、脚本属性和定时触发器。

Revoke Google access in account connections, disconnect the ChatGPT plugin, and delete Cloudflare Health tokens, cache and MCP grants. Revocation does not delete independent archives; remove Drive outputs, script properties and triggers separately if applicable.

网站 / Website

页面无广告或分析追踪。本地快照查看器仅在浏览器内存处理主动选择的文件，不上传、不持久保存。主机可能记录请求日志，由维护者管理其保留。OAuth 流程使用提供程序管理的安全状态及必要 Cookie。

No advertising or analytics tracking is embedded. The local viewer processes selected files in browser memory without upload or persistence. Hosting may retain request logs under the maintainer's configuration. OAuth uses provider-managed secure state and necessary cookies.

Google API 数据的使用和转移遵守 Google API Services User Data Policy，包括 Limited Use。The use and transfer of Google API data follows that policy, including Limited Use.

功能和用途变更时维护者应更新本政策。The maintainer must update this policy when functionality or purposes change.
