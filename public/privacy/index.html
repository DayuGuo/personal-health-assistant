隐私政策

适用应用：Personal Health Assistant
更新日期：2026 年 11 月 6 日

维护者与适用范围

本应用由 Dayu（大宇）维护，仅用于本人 Google 账户的私人健康记录整理。本政策说明应用与本说明网站的数据处理方式。

访问哪些数据，为什么访问

经本人明确同意，应用读取 Google Health 中可用的活动与健身、健康指标与测量、睡眠数据，用于生成私人每日摘要和描述性趋势。只申请对应三项 googlehealth.*.readonly 权限，不写入或修改健康来源记录。

Google Drive 使用 drive.file 权限，读写本应用创建或明确授权给本应用的文件；不申请整个 Drive 的访问权限。Apps Script 使用外部请求权限调用 Google API，并使用脚本触发器权限安排每日同步。

处理与存储

健康数据由 Cloudflare Worker 按需向 Google Health 查询，查询结果在 Cloudflare KV 缓存最多 5 分钟，并经本人已授权的 ChatGPT MCP 连接提供给 OpenAI 服务进行本次请求的处理，适用本人账户及工作区的数据控制设置。桥接所用客户端密钥保存在 Worker Secrets，Google 访问及刷新令牌保存在受限 KV；MCP 客户端授权记录由 Cloudflare OAuth 库管理。独立的 Apps Script 每日任务继续将快照、CSV、简报、manifest 与状态保存到本人 Drive；其客户端配置和令牌分别保存在脚本属性及用户属性。拥有该脚本或云盘文件访问权限的人可能访问相关内容，因此应保持项目与健康输出私有。

共享与有限使用

本应用不出售健康数据，不将其用于广告、征信、保险决策或训练通用 AI 模型；原 Apps Script 不调用 AI 服务。MCP 桥按本人的查询将必要结果提供给本人已连接的 ChatGPT/OpenAI，Cloudflare 负责托管、凭据存储与短时缓存；不声称健康数据从不经过第三方。应用对 Google API 数据的使用和转移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留与删除

输出文件与历史快照保留在本人 Drive，直到本人主动删除；当前版本不设自动清理期限。停止同步可删除 Apps Script 中的 syncDaily 触发器。可在 Google 账户连接设置撤销授权。撤销授权不会自动删除已生成的文件；彻底清理时还需删除 Drive 输出、相关脚本用户属性及脚本属性，并按需删除 OAuth 客户端。

说明网站与服务器日志

本网站为静态说明页面，不嵌入分析统计、广告、第三方字体或追踪脚本，不主动设置 Cookie。可视化页面可读取使用者主动选择的本地 JSON 快照；文件仅在当前浏览器页面内存中处理，不上传至服务器、不写入浏览器持久存储，刷新或关闭页面会清除当前图表。部署后的托管服务器可能按其配置记录 IP 地址、请求时间、路径和浏览器信息，用于运行与排错；这些日志的保留由站点维护者的服务器设置决定。

选择、变更与联系

可随时撤销 Google 授权、在 ChatGPT 断开 MCP 连接或停止使用。若需彻底清理，还应删除 Cloudflare 的健康令牌及缓存 namespace、撤销 MCP 授权记录、按需删除 Worker 与客户端配置。应用功能或数据用途变化时，会相应更新本政策及更新日期。隐私相关问题请联系 guozydayu@gmail.com。
