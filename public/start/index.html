读懂数据状态 / Understand data status

  • 记录日期 / Record date：数据所属日期，不等于抓取时间。
  • API 获取时间 / API retrieval：桥查询 Google 的时间，不是设备最后同步时间。
  • 缓存 / Cache：最多五分钟，命中缓存不代表刚从设备同步。
  • 无记录 / No records：不等于零；授权失败、权限不足和限流会单独报告。
  • 比较 / Comparison：至少 4/7 个近期有效日及 14/28 个历史有效日；这是数据覆盖要求，不是医学阈值。

排错时在 dot 请求 get_data_status，可查看日期、新鲜度和修复建议，不展示具体健康数值。
